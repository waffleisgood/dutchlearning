# 로그인 · 학습 기록 저장 · 피드백 켜기 (Firebase, 무료)

사이트 코드는 다 준비되어 있어요. 아래 5단계로 Firebase 프로젝트만 만들면 켜져요. (약 10분)
무료 Spark 요금제로 충분해요. 결제 카드 등록도 필요 없어요.

## 1. 프로젝트 만들기
1. https://console.firebase.google.com 에 관리자 구글 계정으로 들어가요.
2. **프로젝트 추가** → 이름 `wafel-nederlands` (아무거나 괜찮아요) → Google 애널리틱스는 **끔** → 만들기.

## 2. 로그인 방법 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **Sign-in method** 탭:
   - **Google** → 사용 설정 → 프로젝트 지원 이메일 선택 → 저장
   - **이메일/비밀번호** → 사용 설정(첫 번째 스위치만) → 저장
3. **설정** 탭 → **승인된 도메인** → **도메인 추가** → `waffleisgood.github.io`

## 3. 웹 앱 등록 → 설정값 복사
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱** → 웹 아이콘 `</>`.
2. 앱 닉네임 `wafel-web` → 앱 등록 (Hosting 체크는 하지 않아요).
3. 화면에 나오는 `const firebaseConfig = { ... }` 의 `{ ... }` 부분을 복사해서
   `js/firebase-config.js` 의 `window.FIREBASE_CONFIG = null;` 을
   `window.FIREBASE_CONFIG = { ...붙여넣기... };` 로 바꿔요.
   (이 값은 공개되어도 괜찮아요. 보안은 4단계의 규칙이 지켜요.)

## 4. 데이터베이스(Firestore) 만들기 + 보안 규칙
1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치: `europe-west1 (Belgium)` → **프로덕션 모드** → 만들기.
3. **규칙** 탭 → 내용을 모두 지우고 이 저장소의 `firestore.rules` 내용을 붙여 넣어요.
4. `ADMIN_EMAIL` 을 **피드백을 읽을 관리자 구글 이메일**로 바꾸고 → **게시**.

## 5. 올리고 확인
1. `js/firebase-config.js` 를 커밋하고 GitHub에 push → 1~2분 뒤 사이트에 반영돼요.
2. 사이트 툴바의 **Login** → Google로 로그인 → 상태 줄에 `☁ 모든 기기에 저장됨` 이 보이면 성공.
3. 관리자 계정으로 로그인하면 Login 창에 **받은 피드백 보기** 버튼이 생겨요. 주소 `#admin` 으로도 들어갈 수 있어요.

## 어떻게 동작하나요?
- **학습 기록**: `users/{사용자ID}` 문서에 레슨 점수, 트레이너 진도, 오답노트, de/het 기록, 실생활 표현 점수를 저장해요. 본인만 읽고 쓸 수 있어요.
  다른 기기에서 로그인하면 두 기록을 합쳐요(점수와 진도는 더 높은 쪽, 오답노트는 합치기).
- **피드백**: `feedback` 컬렉션에 제목, 내용, 시간, (로그인했다면) 보낸 사람이 저장돼요. 누구나 **보내기만** 할 수 있고, **읽기·삭제는 관리자 이메일(구글 로그인)만** 가능해요.
- 무료 한도: 하루 읽기 5만 회, 쓰기 2만 회. 이 사이트 규모에서는 넉넉해요.
- 피드백이 오면 메일로도 받고 싶다면: Firebase 확장 프로그램 "Trigger Email" 을 쓰면 되지만 유료(Blaze) 요금제가 필요해요. 지금은 사이트의 `#admin` 에서 확인해요.
